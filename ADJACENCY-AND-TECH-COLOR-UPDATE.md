# Technology grouping and color clarity update

- **Goal-first behavior retained.** A selected goal still decides the supercharged plan and selected high-priority family placement, and it cannot be evicted for adjacency.
- **Adjacency for all compatible systems.** Every verified same-family or documented cross-family link has a baseline reward, even at goal weight zero. Goal weights add extra value rather than suppressing secondary systems.
- **Less fragmentation.** Secondary technology groups incur spread/disconnection penalties, and a legal local-repair pass tries obvious pairwise connections that stochastic optimization missed. It never changes the chosen supercharged set.
- **No fabricated adjacency.** The technology compatibility table is unchanged; standalone upgrades, unverified Corvette reactors and other non-adjacent technologies are not linked.
- **Expanded color grading.** Technology families now use stable, individually distributed colors across the grid, sidebar, blueprint icons, inspector and Corvette technology selector. Family short codes are shown on occupied grid tiles so identification does not rely on color alone.
- **Themes and purple slots preserved.** Interface theme switcher still controls app chrome; supercharged outlines remain purple.

These relative planning scores are heuristics, not No Man's Sky's hidden stat formula.
