# ATLAS MAX — Signal Themes

Five interface themes, accessible from a theme selector automatically added to the bottom of the ATLAS MAX page.

- **Atlas:** Red / crimson
- **Void Mother:** Purple / violet
- **Vy’keen:** Green / emerald
- **Gek:** Orange / amber
- **Korvax:** Blue / cobalt

The switcher changes interface accent variables, navigation highlights, and background atmosphere. **Supercharged slots stay purple** in all five themes, and equipment-specific gameplay indicators keep their existing meaning. Themes change presentation, never the optimizer, adjacency rules, saved gear, or Corvette construction logic.

Choices persist between visits using a separate browser-storage key. This does not restore or persist loadout information; ATLAS MAX can still begin each session with a clean equipment workspace.

This package is an **additive theme extension**, not a replacement for the six-category website. It does not contain the original equipment catalogs or optimizer.
